Personal-use Google Drive integration

macspy Drive Transfer

A personal Google Drive OAuth configuration used with the open-source Rclone command-line application to download large folders and files reliably to a local computer.

What this configuration does

  • Connects an authorized Google account to a locally installed Rclone client.
  • Lists folders and downloads original files, including large video footage and nested project folders.
  • Preserves directory structure, retries interrupted transfers, and allows file verification.
  • Lets the authorized user select a local destination for downloaded files.

Why Google Drive permission is requested

Rclone needs Google Drive API access to identify folders, read file metadata, and download the files that the signed-in Google account is authorized to access. The intended usage is read-only; the configuration does not require permission to upload, modify, or delete Google Drive files.

Authentication is performed through Google's OAuth flow. Rclone uses the authorization token on the user's own computer to make the requested Google Drive API calls.

Access is limited to what Google permits for the account and what the granted OAuth scopes allow. No access to a file is possible merely because someone knows its name.

How Google account data is handled

This repository provides documentation and a personal OAuth configuration; it is not a hosted file-transfer service. The actual transfers run locally through Rclone. File data and access tokens are not submitted to this website.

See the Privacy Policy for the types of Google data accessed, local token and download storage, use and retention, sharing, and how to revoke access.

This is an independent personal-use integration, not an official Google or Rclone product. Rclone itself is developed and maintained by the Rclone project at rclone.org.
