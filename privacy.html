Privacy Policy

Service: macspy Drive Transfer (personal Rclone Google Drive OAuth configuration)
Effective: October 26, 2026

This Privacy Policy explains how Google user data is accessed and handled when using this personal OAuth configuration with the open-source Rclone program. This website is informational; it is not a cloud-based file-transfer service.

1. Purpose and functionality

This configuration lets an authorized user connect Google Drive to Rclone on their own computer to browse folders, download selected files and nested directory structures, retry transfers, and verify downloaded data. The intended permission is read-only. It does not need to create, modify, or delete files in Google Drive.

2. Google user data accessed

When the user authorizes Rclone through Google OAuth, Rclone may access data available to that Google account under the consented Google Drive scope, including:

  • Google Drive file and folder names, identifiers, organization, file types, sizes, timestamps, and other metadata necessary to locate and check files;
  • Contents of files the user chooses to download or verify; and
  • OAuth authorization credentials (including access and refresh tokens) needed to maintain the authorized Google Drive connection.

The Google authorization screen determines the exact permissions granted. Users should choose the read-only Drive scope for this use case.

3. How the data is used

Data is used solely to carry out user-initiated file listing, local downloads, retries, and transfer verification. Google Drive access is not used for advertising, profiling, analytics, sale of information, or training generalized AI models. This personal configuration does not operate any server that receives users' Google Drive files or OAuth tokens.

4. Storage and security

The Rclone program runs locally. Downloaded files are stored in the destination folders chosen by the user. OAuth credentials are stored locally in the user's Rclone configuration unless the user separately configures another storage method. Rclone may also create local logs or cache data depending on how it is run; logs can include file names, paths, errors, and transfer details.

Users are responsible for securing their device, configuration file, downloaded files, backups, and any log files. Do not commit OAuth credentials or private Drive contents to this public GitHub repository.

5. Sharing, disclosures, and third parties

This project does not sell, rent, share for advertising, or transmit Google user data to the operator through this website. Rclone communicates with Google's Drive APIs to perform authorized transfers. If the user independently configures Rclone to copy data to another remote or service, that destination's privacy terms also apply; that is outside this personal download configuration.

The informational website is hosted using GitHub Pages. GitHub may process routine website-visit information under GitHub's privacy statement. This website does not include custom analytics, third-party advertising scripts, or a file-upload form.

6. Retention and deletion

Downloaded files remain on the user's chosen storage until the user deletes them. Locally saved OAuth credentials remain until removed or revoked. To stop access, revoke the app's access in Google Account connections and remove the applicable Rclone remote/configuration and locally downloaded files if desired. Removing a local token does not necessarily delete previously downloaded files.

7. User control and permissions

Users choose whether to authorize Google Drive access and which folders to download. They may stop using this configuration and revoke authorization at any time. This project does not access Google Drive without an authorization grant and an Rclone operation initiated by the user.

8. Google API Limited Use

The use and transfer of information received from Google APIs through this configuration will adhere to the Google API Services User Data Policy, including its Limited Use requirements. Requested data is used only to provide or improve the user-facing transfer functionality described here.

9. Changes to this policy

Any changes will be published at this URL with an updated effective date. If the project's functionality changes to include a hosted service, telemetry, or different data sharing, this policy must be reviewed and updated before that functionality is introduced.

10. Contact

For privacy questions, contact the repository maintainer through GitHub Issues. Issues are public, so do not post personal file names, Google account details, passwords, or OAuth tokens.
